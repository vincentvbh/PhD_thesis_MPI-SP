
This folder contains various files for the AVX2 implementations.

- Source code shared between cryptographic schemes.
    - `chacha20.[ch]`
    - `crypto_sort.[ch]`
    - `fips202.[ch]`
    - `fips202x4.[ch]`
    - `randombytes.[ch]`
    - `rng.[ch]`
    - `sha2.[ch]`
- Cycle counters for compilation.
    - `cycles.[ch]`
