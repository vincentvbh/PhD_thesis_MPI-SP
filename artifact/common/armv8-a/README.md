
This folder contains various files for the Armv8-A implementations.
Please follow the instructions in `./enable_ccr` while benchmarking on Raspberry pi 4.

- Source code shared between cryptographic schemes.
    - `chacha20.[ch]`
    - `crypto_sort.[ch]`
    - `feat.S`
    - `fips202.[ch]`
    - `fips202x2.[ch]`
    - `randombytes.[ch]`
    - `rng.[ch]`
    - `sha2.[ch]`
- Cycle counters for compilation.
    - `enable_ccr`
    - `cycles.[ch]`
